### 👋 Hi, I’m *Génesis*

I'm a **Product Designer with a technical and visual background**, interested in how research, interaction and technology come together to shape useful digital products.

My path into product design hasn't been completely linear. I started with art and visual creation, explored **3D and animation**, moved into **software development and data**, and eventually found the space where those different interests make the most sense together: designing digital products.

That background means I'm comfortable moving between **research, UX flows, interface design and prototyping**, while also understanding how products are structured and built.

I especially enjoy projects where design needs to make something complex feel simple, clear and intentional.

## ✦ Product Design

### 🌊 AEGEA — Interactive Learning Experience

A digital learning experience built around Greek mythology, designed to make educational content feel more visual, exploratory and engaging.

AEGEA started as a development project and gradually became an opportunity to rethink the experience from a product perspective. I worked across the visual direction, information architecture, navigation and interaction, creating a consistent experience across web and mobile.

The project combines a Mediterranean-inspired visual system with watercolour illustration, interactive content and an exploratory map experience.

### 💬 LinguaApp — Language Learning Experience

A mobile language-learning experience designed from research to prototype.

The project started by looking at how people approach language learning and the difficulties that can make it hard to stay consistent. Those findings shaped the user flows, structure and interface, with the aim of creating an experience that feels simple, approachable and easy to return to.

The process covered research, user needs, information architecture, flows, wireframes, UI design and interactive prototyping.

[View the full case study →](https://genesisvaca.dev)

### 🎓 Portal de Becas — Scholarship Management Application

A desktop application for managing Spanish scholarship applications and their different states.

The project covers the complete flow around users, applications and scholarship status management, with an interface designed to keep the different actions and information easy to navigate.

Alongside the application itself, I created the supporting documentation and user manual, making this a more complete software project rather than just an isolated technical exercise.

### 👖 Sweet Jeans — From First Website to Modern Frontend

Sweet Jeans started in 2023 as the first website I built, using HTML, CSS and a small amount of JavaScript.

Rather than leaving it as an old student project, I revisited it later and rebuilt the experience with a more modern frontend stack. The redesign gave me a way to look back at my first approach to layout, structure and UI and compare it directly with how I build interfaces now.

The before-and-after is what makes this project interesting to me: the idea stayed the same, but the implementation, structure and visual decisions evolved with my skills.

[View the original project →](https://github.com/genesisvaca/My-First-Website)

## 📊 Data & Analytics

### 📈 Product Sales & Trends — Power BI

An end-to-end data analytics project focused on understanding product performance, sales trends and key business metrics.

Built as part of my Master's programme, the project covers the process from preparing and transforming the data to modelling it, creating DAX measures and turning the results into an interactive Power BI dashboard.

Beyond the technical work, the focus was on deciding which information actually mattered and presenting it in a way that made patterns and performance easier to understand.

[View project on GitHub →](https://github.com/genesisvaca/PowerBI-Obtencion_Manipulacion)
